## han-equipment 独立维护首个版本

`2.0.0` 是 **han-equipment** 由 [Hanserwei](https://github.com/Hanserwei) 独立维护后发布的首个版本。项目基于困困鱼的 [plugin-equipment](https://github.com/chengzhongxue/plugin-equipment) 继续开发，使用独立的插件标识、数据与权限命名空间。

han-equipment 用于在 Halo 博客中展示你日常使用的电脑、手机、外设与操作系统：在 Console 中维护装备资料，在前台用分组和卡片展示。

## 本版功能

- **装备分类与参数模板**：支持台式机、笔记本、手机、平板、外设、操作系统及其他装备，按设备类型补充常用参数。
- **结构化配置参数**：参数按顺序展示，可增删和排序，允许重复名称及多行内容，适合描述多块硬盘、多台显示器等配置。
- **使用状态与重点展示**：标记使用中、备用或已退役；为主力设备启用宽卡片。
- **图片与使用记录**：填写图片、产品链接、概述和使用感受；未设置图片时显示设备类型图标。
- **分组管理**：支持分组、排序和批量操作，按不同用途组织装备清单。
- **主题集成**：提供响应式展示页面与可复用的 Thymeleaf 卡片，支持深色模式；前台地址为 `/equipments`。
- **自动构建与发布**：GitHub Release 发布后自动执行前后端测试、类型检查、lint 和 JAR 验证，上传安装包及 SHA-256 校验和；支持指定标签的手动构建和补传。

## 安装要求与步骤

需要 **Halo 2.26.0 或更高版本**。

1. 下载本页附件中的 **`han-equipment-2.0.0.jar`**。
2. 在 Halo Console 的“插件”页面选择本地安装并上传 JAR。
3. 启用 **han-equipment**，进入左侧 **Han 装备** 菜单。
4. 创建分组、添加装备并填写参数，访问 `/equipments` 查看效果。

`Source code (zip/tar.gz)` 是源码，不作为插件安装包使用。下载后可将 JAR 和校验和放在同一目录，执行：

```bash
sha256sum -c han-equipment-2.0.0.jar.sha256
```

## 从旧 equipment 切换

**han-equipment 与旧 `equipment` 是两个独立插件，旧数据不会自动迁移。** 切换前请备份原装备数据与站点；两个插件共用 `/equipments` 路由，请先停用旧插件，再启用 han-equipment。

已有主题如果覆盖了装备页面，需要同步修改插件片段和资源路径：

- 模板片段使用 `plugin:han-equipment:modules/equipment :: list(groups=${groups})`。
- 样式地址使用 `/plugins/han-equipment/assets/static/equipment.css`。
- 使用 Finder 的模板改用 `hanEquipmentFinder`。

完整示例见 [主题适配指南](https://github.com/Hanserwei/plugin-equipment/blob/2.0.0/docs/theme-integration.md)。插件不会自动修改你的主题文件。
